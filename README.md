# KaazDaak website

Next.js app for the KaazDaak product site (Bangla-first local work marketplace).

- Dev: `npm install && npm run dev` → http://localhost:3001
- Sibling app: OceanEdge Technologies site in `../frontend` → http://localhost:3000

Cross-site links use `NEXT_PUBLIC_OCEANEDGE_URL` (defaults to `http://localhost:3000`
in development, `https://oceanedgetech.com` otherwise).

The previous static build lives in `legacy/`.
